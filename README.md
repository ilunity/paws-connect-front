## Учебный проект. Web-приложение "Агрегатор животных из приютов". Клиентская часть.

### Цель
Создание web-приложения, которое объединяет информацию о приютах для животных и помогает людям найти идеального питомца.

### Функциональность
- Поиск животных. Фильтрация по городу, возрасту и полу.
- Просмотр фотографий и описаний животных.
- Регистрация приюта с указанием описания и контактной информации.
- Добавление информации о животных, находящихся в приюте.
- Регистрация пользователей с помощью MagicLink (ссылка на электронную почту).

## Стэк
- TypeScript
- React
- Next.js
- Antd
- Clerk (сервис для аутентификации и управления пользователями)
